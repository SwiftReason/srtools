# SR Tools

SR Tools is a collection of open-source Windows utilities for system cleanup, troubleshooting, and maintenance.

## Tools

### AMD Chipset Cleanup Utility

Fixes AMD chipset installer hangs caused by Windows Update, MSI state, and leftover installer files.

Location: `tools/amd-chipset-cleanup`

### Temp File Cleaner Utility

A modern Windows cleanup utility with a GUI, light and dark themes, scan mode, cleanup presets, summary reporting, and safer aggressive options.

Location: `tools/temp-file-cleaner-utility`

## Goals

* Simple and effective utilities
* Transparent and open source
* Safe cleanup operations
* Easy local execution

## Notes

These tools may require administrator privileges and can make system-level changes. Review each tool’s README before running.
