# AMD Chipset Cleanup Utility

Fixes AMD chipset installer issues caused by Windows Update, MSI state, and leftover installer files.

## What it does
- Stops update/install services
- Clears Windows Update cache
- Removes AMD temp files (Deep Cleanup)

## How to use
1. Run the launcher as Administrator
2. Start with Basic Cleanup
3. Use Deep Cleanup if needed

## Notes
Does not uninstall chipset drivers.
